# SOLA TUBE

SOLAブランドの動画サイト。既存のVue 3 + Viteフロントエンド、Expressバックエンドを引き継いで開発しています。

## ローカル起動
- Node.js 20以上、npm 11以上
- `npm install`（インストール時にyt-dlpのセットアップとVueのビルドを実行）
- `npm start`
- `http://localhost:3000` を開く

## Render
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- PORTはRenderから自動的に設定されます。

## 開発状況
この作業ブランチではページタイトル・メタデータ・起動アニメーション・パッケージ名をSOLA TUBE向けに変更しました。
動画検索や再生などの既存機能は維持する方針です。これらの機能の実行確認と、画面内の旧ブランド表記の置き換えはまだ完了していません。
